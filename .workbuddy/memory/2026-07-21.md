## 排查 Qdrant 连接错误
- 用户运行 `qdrant_client_manager.py` 时报 `WinError 10061`（连接被拒绝）
- 排查结果：Qdrant Docker 容器从未被创建，`docker compose up -d` 从未执行
- Docker daemon 运行正常（v29.6.1），端口 6333 未被占用，配置文件无问题
- 根本原因：所有 Docker Compose 服务（MySQL/Qdrant/ES/Kibana/Embedding）均未启动
- 解决方案：在 `docker/` 目录下执行 `docker compose up -d` 启动全部服务
