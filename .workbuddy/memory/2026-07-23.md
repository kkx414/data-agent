## 修复 log.py 中 PermissionError 的 bug
- build_meta_knowledge.py 运行时报 PermissionError: Permission denied: 'app/scripts/logs/app.log'
- 根因：`path.mkdir()` 将整个路径（含文件名 app.log）当作目录创建，app.log 被创建成了目录而非文件。logger.add() 尝试往目录里写文件 → Windows 拒绝 → PermissionError
- 修复：`path.mkdir()` → `path.parent.mkdir()`（只创建父目录），同时 `path.resolve()` 转为绝对路径避免 CWD 依赖
- 清理了被错误创建的两个 app.log 目录（项目根目录 logs/ 下和 app/scripts/logs/ 下）
